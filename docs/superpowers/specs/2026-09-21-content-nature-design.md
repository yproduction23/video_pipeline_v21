# 콘텐츠 성격(사실성 등급) 기반 대본 생성 설계 (덩어리 ②)

## 배경과 목표
덩어리 ①(벤치마크 발견 → 제작 시작)로 비경제 소재(예: 부산상어)를 고를 수 있게 됐지만, 대본 생성은 금융 전제에 묶여 있다.
(팩트체크 프롬프트가 "한국 주식 시장 전문", 카테고리 기본값 "주식시장 전반", 시장 데이터 수집, 근거 부족 시 반려)
경제·시사·화제 콘텐츠·야담을 한 파이프라인에서 만들 수 있게 한다.

## 설계 원칙 (최상위)
1. **대본의 중심은 궁금증이다.** 수치(지수, 환율 등)는 이야기를 받치는 재료일 뿐이며, 시청자가 궁금해할 지점을 짚으며 이야기를 끌고 가는 것이 목적이다. 이 원칙은 등급별 프롬프트 3종에 공통으로 넣는다.
2. **벤치마크 영상은 1차 근거다.** 이미 검증된 원본으로 취급한다. 검증 시스템이 확인하지 못했다는 이유로 내용을 빼지 않는다.
3. **팩트체크는 표시 도구다.** 삭제·반려는 "명백한 오류"로 확인된 경우에만 한다. 확인 못 한 수치·인용은 완화 표현("~로 알려져 있습니다")이나 검토 필요 표시로 남긴다.
4. **사실과 견해를 구분한다.** 전문가마다 시각이 갈리는 내용은 "누가 그렇게 본다"로 쓴다. 견해가 갈린다는 사실 자체를 재료로 쓴다.

## 콘텐츠 성격(등급)
| 등급 | 예시 | 1차 근거 | 검증 실패 시 | 영상 안 표기 |
|---|---|---|---|---|
| 사실형 (FACTUAL) | 경제, 시사, 사회 이슈 | 뉴스 + 벤치마크 분석 | 완화 표현 + 표시, 반려 안 함 | 견해는 관점 표기 |
| 해설형 (EXPLAINER) | 화제 콘텐츠, 밈, 인물 | 벤치마크 분석 + 웹 검색 (시장 데이터 수집 안 함) | 완화 표현 + 표시 | 불확실 내용은 완화 표현, 견해는 관점 표기 |
| 창작형 (STORY) | 야담, 옛날이야기풍 | 벤치마크의 전제·긴장 구조만 참고(인물·지명·사건·결말은 새로 창작, 원작 줄거리·설명·태그는 차단) | 해당 없음 | 도입부에 "지어낸 이야기입니다" 표기 필수 |

## 등급 결정 흐름 (채널 기본값 + 작업별 확정)
- 제작 채널(ChannelProfile)에 `contentNature` 기본값 추가. 기본 FACTUAL이므로 기존 채널 동작은 변하지 않는다.
- 작업 생성 시 등급 칸이 채널 기본값으로 채워진다. 벤치마크로 시작하면 영상 제목·분석으로 등급을 **추천**하고, 채널 기본값과 다르면 안내한다. 확정은 사용자가 한다.
- 확정 등급은 Job에 저장되어 근거 수집·대본 생성·팩트체크가 같은 값을 쓴다. 작업 도중 바뀌지 않는다.
- 창작/해설을 사실형으로 바꾸면 경고만 하고 막지 않는다.

## 대본 생성 변경점
- 팩트체크 시스템 프롬프트를 등급별 3종으로 분리(현재 "한국 주식 시장 전문 팩트체커" 고정).
- 카테고리 기본 라벨 "주식시장 전반" 제거. 등급·주제에 맞는 라벨 사용.
- 시장 데이터 수집(`collect_for_category`)은 FACTUAL이면서 경제 카테고리일 때만.
- 경제 전용 규칙(시장 연결 금지, 매크로 점수 등)은 FACTUAL에서만 적용(기존 카테고리 분기의 확장).
- 근거 부족 반려(Spring `ScriptResearchRequiredException` → 키워드 선택으로 복귀)를 **모든 등급에서 "경고 후 진행"으로 완화**한다.
- 벤치마크 모방 규칙 유지: 문장은 복제하지 않고 훅의 유형·구조·리듬만 참고.

## 범위 밖
- 댓글 수집, 자막(트랜스크립트) 구조 분석(별도 단계).
- 등급별 영상 시각 연출(썸네일·장면 이미지 규칙) 변경.

## 테스트
- 등급별 프롬프트 선택, 창작형 표기 문구 포함, 해설형 대본에 근거 없는 수치 미잔존, 검증 실패 시 반려되지 않고 진행됨을 자동 테스트로 확인.
- 실제 소재(해설형: 부산상어류, 창작형: 야담)로 대본 1편씩 생성해 수동 확인(Anthropic 크레딧 소모).

## 위험
- 기존 경제 영상 경로에 영향: 반려 완화와 프롬프트 분리는 회귀 테스트로 보호한다.
- 등급 오분류로 창작 이야기가 사실처럼 나가는 위험: 작업별 사용자 확정과 창작형 표기 필수 문구로 완화한다.
